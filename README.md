# Pocketbook

A simple personal expense manager for iPhone and Android. Offline, no account, your data stays on your phone. Built with Laravel and NativePHP Mobile.

Start with `CLAUDE.md`. Product and design documents are in `docs/`:

- `docs/SPEC.md` product decisions, money rules, data model
- `docs/SCREENS.md` every screen, element and option
- `docs/FLOWS.md` user journeys
- `docs/GAPS.md` what is not designed yet and open decisions
- `docs/design/` tokens, screens as static HTML (`screens/index.html`), components

Design (online): screens https://claude.ai/artifact/McKtWDuTK1kgQKSnffzJrs , design system https://claude.ai/artifact/JkVyy5F7v7a6TFdGPV2Tnc
