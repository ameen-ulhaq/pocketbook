# Design reference

- `tokens.json`: the design tokens (source of truth). `tokens.css` is generated from it.
- `screens/`: the 21 designed screens as static HTML. Open `screens/index.html`. Reference only: they use raw hex values; build with the tokens.
- `components/`: guidelines and a live preview for each component (Button, Field, Chip, TransactionRow, BalanceCard, BottomNav, ProgressBar).
- Online: screens https://claude.ai/artifact/McKtWDuTK1kgQKSnffzJrs , design system https://claude.ai/artifact/JkVyy5F7v7a6TFdGPV2Tnc (private to the owner; the files here are the portable copy).
