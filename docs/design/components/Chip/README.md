Three small selection controls.

- **Filter chips** (36px): one selected at a time, selected is solid `accent`. A row that overflows scrolls sideways and keeps `space-5` padding at the end.
- **Segmented control** (42px segments in a `surface-tint` track): switch between 2–4 views of the same screen (Expense, Income, Transfer).
- **Pills** (`caption`, `radius-pill`): status in words, never alone: Paid, Part paid, Owes, Due 20 Nov, Over by $12.
