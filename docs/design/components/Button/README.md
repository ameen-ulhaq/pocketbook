Full-width action button, 52px high. One primary per screen.

- **Primary** (`accent`, `on-accent` text): the one action that finishes the screen: Save, Add, Record payment.
- **Secondary** (`surface`, `line` border): everything else: Edit, Remind, Share summary.
- **Danger** (`expense` text): Delete only. Always confirm.
- Buttons fill the width between the `space-5` screen padding, so the gap on the right equals the gap on the left. Two buttons side by side share the row with a 10px gap.
- Label is a verb in sentence case; an icon is optional and goes before the label.
